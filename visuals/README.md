# miassembler metro map

`miassembler_metromap.svg` / `.png` follow the nf-core
[workflow schematic guidelines](https://nf-co.re/docs/community/brand/workflow-schematics)
and the style of our other pipeline maps
([nf-core/seqsubmit](https://github.com/nf-core/seqsubmit),
[genomes-generation](https://github.com/EBI-Metagenomics/genomes-generation)):

- one coloured line per read type (short reads, ONT HQ/LQ, PacBio CLR/HiFi), running in parallel through shared steps;
- numbered grey boxes for pipeline stages;
- tool name (bold) above each station, short description below;
- mandatory steps drawn as stations with a black dot, optional steps (depending on parameters or the samplesheet) as empty stations;
- input/output file icons, an input triangle and an output bar.

The map is generated by `make_metromap.py` (no dependencies). Edit the `STATIONS`/`STAGES`
lists when the pipeline changes, then regenerate:

```bash
# Maven Pro is the nf-core brand font; it is embedded in the SVG so it renders the same everywhere
curl -L -o MavenPro.ttf "https://github.com/google/fonts/raw/main/ofl/mavenpro/MavenPro%5Bwght%5D.ttf"
python3 visuals/make_metromap.py --font MavenPro.ttf

# PNG for the README, via headless Chrome (or Inkscape / rsvg-convert)
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless \
    --screenshot=visuals/miassembler_metromap.png --window-size=3260,1200 \
    --hide-scrollbars "file://$PWD/visuals/miassembler_metromap.svg"
```
